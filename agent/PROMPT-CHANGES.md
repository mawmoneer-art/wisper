# What changed from the draft prompt, and why

Your draft was already close. These are the edits, each with the alternative I did not take.

1. Variable syntax is now `{{my_name}}` style. Vapi substitutes double curly braces, not single ones. No alternative here, it is just the platform's syntax.

2. The first sentence is a fixed First Message, not generated by the model. It says it is an AI assistant for you and asks if it has the right person. The disclosure is the one line that must never be paraphrased away, so it is hard-coded. Alternative: let the model open the call. Rejected, one bad paraphrase and you have a compliance problem.

3. Time is passed in as `{{when_spoken}}`, already written in words by the trigger script, for example "Tuesday the ninth of September at three in the afternoon". The prompt tells the model to say it exactly as given. Alternative: give the model an ISO timestamp and ask it to convert. Rejected, models get timezones wrong under pressure and you would never know until a caller turns up on the wrong day.

4. The call flow is written as numbered branches with one ending each. Your draft described behaviour; this one tells the model what to do in every exit. Alternative: keep it short and trust the model. Rejected, the exits are where it will improvise if left alone.

5. Clear-yes rule. "Probably" or "let me check" does not trigger the booking tool. The model asks once more, then treats it as a reschedule. Alternative: book on any positive noise. Rejected, a false booking costs you more than a missed one.

6. Voicemail line moved into Vapi's voicemail message setting, so the platform handles machines without the model. The prompt keeps a fallback line in case detection misses. Alternative: handle voicemail entirely in the prompt. Rejected, detection at the audio level is faster and cheaper.

7. log_outcome is no longer a tool the model must remember to call. A Vapi structured output reads the transcript after every call and fills the schema in outcome-schema.json. It cannot be skipped. Alternative: your original webhook tool. Rejected for reliability, and it also means one fewer server. The schema also records whether the AI disclosure happened, so you can audit that.

8. Added: no collecting personal information, and do not restart after goodbye. Both are cheap guardrails against the two most common ways these calls run long.

Not changed: the ban on discussing commercials, the no-negotiation rule, and the never-human rule. Those were right.
